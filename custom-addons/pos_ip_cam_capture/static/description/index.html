POS IP CAMERA CAPTURE

Description

The Odoo module allows users to enable and configure an IP camera to capture an image when the Payment Button is clicked.

Configuration

Configuration can be accessed through Point of Sale > Settings > External Device, where a checkbox enables users to toggle and configure the IP camera.

Notes

  • If a Point of Sale session is active, a page reload is necessary to apply any changes made to the configuration.
  • Follow the URL pattern according to the protocol to be used, e.g., rtsp://{usr}:{pas}@{ip}:{port}, for specifying user, password, IP camera, and port.
  • The IP camera must be connected to the same LAN.
  • Make sure the Python script WebSocket is running when you use this module.
