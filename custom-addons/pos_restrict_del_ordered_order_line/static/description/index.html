Restrict Erase POS Order Line

Setup

Set a list of authorized users: Point of Sale > Settings > POS > Restaurant & Bar > Multi Employees per Session.

Preview

When the Order button on the Product Screen is clicked, the ordered quantities are set for each line.

When an unauthorized user tries to delete or set a smaller quantity in the order line, an error popup appears.
Note: The quantity can only be edited using the plus and minus buttons located on the order line.
