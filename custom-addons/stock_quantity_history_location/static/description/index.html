This module allows to run an Inventory report or Inventory Valuation report by location, for a past date or for current date.

Odoo 19.0

Uso

First, you need to activate Storage Locations. To do so, go to Inventory / Configuration / Settings / Warehouse and activate it.

To use this module, go to:

  • Inventory / Reporting / Stock

  • Select Inventory at Date & Location. The button is renamed by this module, so that it is clear that a location can be picked as well. Users without the Storage Locations group keep seeing the original Inventory at Date label.

  • Filter by location

  • Optionally: Mark if you want to include child locations

  • Choose a moment in time:

  • Current Inventory
  • At a Specific Date
